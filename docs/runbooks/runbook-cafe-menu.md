# Change Cafe Menu — Racing Point
## When to use this: Add, edit, or remove a cafe menu item

## Step by step:
1. Open Admin → `http://192.168.31.23:3201` → click **Cafe** in the left menu
2. Find the item to edit → click the pencil icon (or **+ Add Item** for new items)
3. Update the name, price, or availability → click **Save**
4. Open POS billing page → `http://192.168.31.20:3200/billing` → verify the item appears within 10 seconds
5. If the item does not appear in 10s → press Ctrl+Shift+R on the POS screen, check again

## If stuck: WhatsApp Bono — screenshot the Admin Cafe page

## DO NOT:
- **DO NOT** edit any `.db` file, `menu_items.db`, or use any script
- **DO NOT** restart any services — the change takes effect automatically
