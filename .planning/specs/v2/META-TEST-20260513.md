## §2 — Design (revised from §S-221.6 original)

**Original §S-221.6 design:** 5 rows × 3 parallel agents (mirroring iter1-4 cascade scale).

**Revised design (this meta-test):** 3 rows × 1 agent.

**Rationale for revision:** Original 5×3 design recreates the exact multi-agent racing pattern Captain flagged as gap-generating. The meta-test purpose is to validate the protections, not to demonstrate scale. 1-agent design:
- Reduces blast radius if F1+F3+MAOR fail to catch a defect
- Eliminates concurrent-cascade-collision class (iter3 §S-218 anchor) — irrelevant to single-agent
- Reduces wall-time + cost (~$0.30 vs ~$1.00; ~15min vs ~30-45min)
- Still exercises full V-LBAC §14.4 cascade flow (OPEN → DESCEND → H1 → F1 GATES → FIX → REVIEW → CLOSE)
- Documented as deliberate design choice; Captain may re-spec at 5×3 if signal insufficient
