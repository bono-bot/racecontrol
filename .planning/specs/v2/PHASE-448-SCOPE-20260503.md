## §2 — Phase 448 typed-getter signatures (draft)

Per V2-ROADMAP §P1.448 scope: "Each getter: reads env, memoizes, returns `Result<SecretString>` (uses `secrecy::SecretString` to prevent accidental log leakage)."

```rust
// crates/rc-common/src/secrets.rs (DRAFT — pending bono AMPLIFIER + Phase 446/447 merge)

use secrecy::SecretString;
use std::sync::OnceLock;
use thiserror::Error;

#[derive(Debug, Error)]
pub enum SecretsError {
    #[error("Missing required env var: {0}")]
    Missing(&'static str),
    #[error("Invalid value for env var {0}: {1}")]
    Invalid(&'static str, String),
}

pub type Result<T> = std::result::Result<T, SecretsError>;

// Memoization slot per getter (OnceLock; thread-safe; loads once per process)
// Pattern: read env, validate, wrap in SecretString, cache.

pub fn jwt_secret() -> Result<&'static SecretString> { ... }
pub fn admin_pin_hash() -> Result<&'static SecretString> { ... }
pub fn terminal_secret() -> Result<&'static SecretString> { ... }
pub fn relay_secret() -> Result<&'static SecretString> { ... }
pub fn evolution_api_key() -> Result<&'static SecretString> { ... }
pub fn gmail_client_secret() -> Result<&'static SecretString> { ... }
pub fn gmail_refresh_token() -> Result<&'static SecretString> { ... }
pub fn sync_hmac_key() -> Result<&'static SecretString> { ... }
pub fn encryption_key() -> Result<&'static [u8; 32]> { ... }  // hex-decoded; binary key
pub fn hmac_key() -> Result<&'static [u8; 32]> { ... }        // hex-decoded; binary key
pub fn openrouter_key() -> Result<&'static SecretString> { ... }
pub fn openrouter_mgmt_key() -> Result<&'static SecretString> { ... }
pub fn anthropic_api_key() -> Result<&'static SecretString> { ... }
```

### §2.1 — Design decisions (pending bono AMPLIFIER)

| # | Decision | Default | Rationale |
|---|---|---|---|
| D1 | Memoization granularity | Per-getter `OnceLock` (one cache slot per getter) | Lazy init; thread-safe; no global mutex; getter that's never called costs zero |
| D2 | Missing-env behavior | Return `Err(SecretsError::Missing(name))` (fail-loud) | Phase 447 EXIT pattern: secrets MUST NOT have hardcoded fallbacks; caller decides whether absence is fatal |
| D3 | Encryption-key / hmac-key return type | `&'static [u8; 32]` (hex-decoded; binary) | Current callsites at crypto/encryption.rs:88,91 do hex decode locally; centralize the decode in the getter |
| D4 | Phase 446 OPENROUTER_KEY dual-read absorption | Phase 448 reads OPENROUTER_KEY only; OPENROUTER_API_KEY fallback REMOVED | Phase 446 dual-read was the migration substrate; Phase 448 is the hard-cut. Pre-condition: production env writers updated to OPENROUTER_KEY (already true per PACT-007 §1.5 audit on the canonical 5 callsites) |
| D5 | Phase 447 TERMINAL_SECRET 3-axis absorption (Q3 of PACT-008) | Phase 448 reads RACECONTROL_TERMINAL_SECRET only; RC_TERMINAL_SECRET + TERMINAL_SECRET fallbacks REMOVED | Pre-condition: Phase 447 substrate ships dual-read shim FIRST + bono Q1 .env migration closes pm2 ecosystem gap. Then Phase 448 hard-cuts to canonical only |

### §2.2 — Invariants Phase 448 establishes

1. **Single owner** — every S-class secret has exactly one read-site (the typed getter); all 18 callsites delegate
2. **No accidental log leakage** — `SecretString` Debug impl prints `[REDACTED]`; cannot accidentally print via `tracing::info!("{:?}", secret)`
3. **Memoization** — each secret loads once per process; subsequent calls O(1)
4. **Fail-loud on missing** — `Err(Missing(name))` at the call-site forces deliberate handling; caller decides default vs panic vs degraded mode
