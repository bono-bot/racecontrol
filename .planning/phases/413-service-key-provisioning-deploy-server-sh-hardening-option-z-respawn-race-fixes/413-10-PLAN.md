# IP spoofing technique

Axum's `ConnectInfo<SocketAddr>` comes from the actual TCP peer IP. To simulate a pod IP on localhost:

- Option A: run racecontrol with `SERVER_HOST=0.0.0.0`, use `curl --interface` if your LAN has a pod online (James .27 can reach pod IPs via Tailscale). Curl from a pod machine.
- Option B: override the middleware behavior in a dev build via env var (anti-pattern — SKIP)
- Option C: use `curl --resolve` to point to localhost but no — the source IP is what matters, not the destination.
- Option D: run the test on a pod or the server itself (real pod-IP source). This is the only reliable technique.

Recommended: run Plan 10 FROM JAMES .27 targeting a dev racecontrol on James itself. Use SSH to a real pod to run a curl from that pod's IP. Validates the full path.

If physical access is unavailable: add a `#[cfg(feature = "dev-bypass-ip")]` short-circuit ONLY for this plan's test — but that's a feature flag ship risk. Prefer the real pod curl.
