# Launch site (start-racecontrol.bat:26)

```bat
start "" /B powershell -ExecutionPolicy Bypass -WindowStyle Hidden -File C:\RacingPoint\start-racecontrol-watchdog.ps1
```

The `""` is the title argument to `start`. Empty string → window gets no title. `/B` means "no new window" anyway. Either way, WINDOWTITLE filter misses it.

# Replacement command

Use WMIC:
```cmd
wmic process where "name='powershell.exe' and commandline like '%%start-racecontrol-watchdog.ps1%%'" delete
```

WMIC is available on all supported Windows Server and Windows 11 versions on the venue server (.23). NOTE: Microsoft has deprecated WMIC in Windows 11 24H2+; if server .23 is on a version that removed WMIC, an alternative is PowerShell `Get-CimInstance`, but the CONTEXT.md explicitly specifies WMIC. Use WMIC. Plan 08 (audit) can surface if 24H2 is a concern.

Escaping: the command runs inside a JSON string inside a curl `-d` argument. The `%` characters need double-percent escaping for cmd.exe (because /exec on the agent side may run via cmd /C). Test by running the exact string first and confirming deletion behavior on the target.
