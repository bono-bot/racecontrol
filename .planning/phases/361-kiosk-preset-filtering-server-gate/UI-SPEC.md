### Surface A — Kiosk InventoryStatusBanner

**Placement:** Top of `SetupWizard.tsx`, rendered INSIDE the existing wizard shell but ABOVE the step content. Not a modal, not an overlay — a sticky banner that pushes step content down. Rendered conditionally only when `inventoryFetchState === "error"`.

**Component tree:**

```
  <StepContent />             {/* existing */}

```

**Banner layout (row, left-to-right):**
```

```

- Container: `bg-rp-card border-l-4 border-rp-red rounded p-4 flex items-start gap-4`

**Visual hierarchy order:** (1) red border strip → (2) warning icon → (3) title → (4) body → (5) Retry CTA → (6) timestamp. Eye travels down then right to the CTA.

### Surface A — presetValidity flow in wizard body

## Interaction States

### InventoryStatusBanner (Surface A)

| State | Visual |
|-------|--------|
| Default (fetch OK) | Banner not rendered at all (null return) |
| Fetch loading (initial) | Banner not rendered — existing wizard spinner covers this. Do NOT show banner during first fetch. |
| Fetch failed | Banner renders with full content, Start Session disabled |
| Retry in progress | Retry button shows `disabled` state (`opacity-50 cursor-wait`), label changes to `Retrying...` |
| Retry success | Banner unmounts (conditional render flips), Start Session re-enables |
| Retry failed again | Banner stays, timestamp updates to new check time |
| Auto-refresh tick (30s) | If banner visible, silent re-fetch. On success: unmount. On failure: timestamp updates only, no flash. |

**No override affordance.** Q1 decision: hard-block only. No "continue anyway" button, no soft-warn path, no admin bypass. The banner is the entire contract of Phase 361.

### Experience row (existing, line 632-672 — migration only)

| State | Visual (current → NEW) |
|-------|------------------------|
| Valid preset | `hover:border-rp-red/50` (unchanged) |
| Invalid preset | `opacity-60 cursor-not-allowed` + `Unavailable` badge. Badge background: `bg-[#E10600]` → **`bg-rp-red`** (migration required) |
| Clicked while invalid | Click handler short-circuits (`if (!isUnavailable)` at line 636 — unchanged) |

### Admin drift page interactions

| State | Visual |
|-------|--------|
| Initial load | Skeleton rows (8 of them) `bg-rp-card animate-pulse h-16` |
| Load success | Rows render with OK/DRIFT status |
| Pod unreachable | Status column: `Unreachable` in `text-rp-grey`, row greyed to `opacity-60`, no expansion |
| API error | Full-page error state (replaces table): `Content drift API unreachable. Check racecontrol server on :8080.` with Refresh CTA |
| Refresh button click | Button shows `Refreshing...`, disabled, triggers re-fetch |
| Auto-refresh tick | Silent background re-fetch, no skeleton flash, timestamps update in place |
| Hover on expanded drift file path | No-op (read-only — v1 has no copy-to-clipboard) |

**Auto-refresh (Q4 decision):** 30-second interval on both surfaces via `setInterval` in `useEffect` cleanup-safe pattern. No polling if page hidden (`document.visibilityState === 'hidden'`) — resume on visibility change.

## Accessibility

| Requirement | Implementation |
|-------------|----------------|
| Color contrast | Racing Red `#E10600` on white: 4.52:1 (AA pass for non-text). White on Racing Red: 4.52:1 (AA large text pass). White on `#1A1A1A`: 17.4:1 (AAA). White on `#222222`: 15.3:1 (AAA). Grey `#5A5A5A` on `#222222`: 2.1:1 — ONLY allowed for decorative/metadata text (timestamps), never for primary copy. |
| Never convey state by color alone | P0 MISSING rows have `border-l-4 border-rp-red` AND text label `Missing from disk (blocks launches)` AND icon. Not just red. |
| Banner is an alert | `role="alert" aria-live="assertive"` on the banner container so screen readers announce it immediately on mount. |
| Start Session disabled state | `aria-disabled="true"` + `aria-describedby` pointing to banner ID. Tooltip label: `Pod inventory unreachable — retry to continue`. |
| Retry button | Native `<button>`, focus ring `focus:ring-2 focus:ring-rp-red focus:ring-offset-2 focus:ring-offset-rp-card`. |
| Keyboard nav | All interactive elements reachable via Tab. Retry button receives auto-focus on banner mount (`useEffect` + `ref.current?.focus()`). |
| Drift table | Semantic `<table>` with `<thead>` and scope attributes, not divs. Screen readers announce "Pod 2, DRIFT, 2 missing, 5 extra". |
| Expanded drift details | Use `<details open>` + `<summary>` semantics so the expansion state is announced. |
| Icon-only affordances | None in this phase. If added later, require `aria-label`. |
| Reduced motion | Skeleton pulse and auto-refresh spinner respect `prefers-reduced-motion`: `motion-safe:animate-pulse`. |
