Wave 4 — Backend wiring + 3 surface fixes. This plan does the actual end-to-end backend work that makes continuous billing functional:

1. **handle_game_off rewrite** — replace `end_billing_session(EndedEarly)` (line ~329) with `BillingEvent::GameStopped` FSM transition. Game stop no longer ends billing; meter pauses.
2. **handle_live_resume reset** — when WaitingForGame → Active happens (game launches again), reset `between_games_idle_seconds=0` and `idle_warning_sent=false` for clean re-entry into the warning cycle.
3. **15-min auto-end in tick_all_timers** — when idle >= 900s, queue session for `end_billing_session(BillingEvent::End)` post-lock. **Status becomes `Completed`** per CONTEXT.md D-IDLE-AUTOEND lock (NOT EndedEarly).
4. **Surface fix #1 — `api/billing_session::stop_billing` branch** — when staff hits End Session from kiosk and DB status is `waiting_for_game`, NEW logic: if `elapsed_seconds > 0` → bill cumulative via **EndEarly → EndedEarly** (staff-triggered, per CONTEXT.md edge case 4), else first-wait CancelledNoPlayable + full refund (existing).
5. **Surface fix #2 — `billing_timer_stale` query filter** — add `AND driving_seconds = 0` so the 5-min stale-cancel doesn't kill mid-stream WaitingForGame sessions whose `created_at` could be hours old.

**B4 distinction (critical):** Two paths from WaitingForGame mid-stream both end the session, but use DIFFERENT FSM transitions:
- **AUTO-END (15-min idle):** `BillingEvent::End` → `Completed` (customer walked away naturally)
- **STAFF-TRIGGERED (stop_billing handler, kiosk End Session button):** `BillingEvent::EndEarly` → `EndedEarly` (explicit early termination)

#[test]
fn cumulative_snap_25_5_yields_pkg_30() {
    // 414-INTEGRATION-01: snap pricing accumulates across game swaps
    let mut timer = BillingTimer::default();

    timer.status = BillingSessionStatus::Active;
    for _ in 0..(25 * 60) { timer.tick(); }
    assert_eq!(timer.elapsed_seconds, 1500);

    timer.status = BillingSessionStatus::WaitingForGame;
    for _ in 0..(7 * 60) { timer.tick(); }
    assert_eq!(timer.elapsed_seconds, 1500, "elapsed_seconds is FROZEN during WaitingForGame");

    timer.status = BillingSessionStatus::Active;
    for _ in 0..(5 * 60) { timer.tick(); }
    assert_eq!(timer.elapsed_seconds, 1800, "elapsed_seconds resumes ticking on Active");

    // Snap to 30-min package: ₹700, NOT 30 × ₹25 = ₹750
    let total_minutes = timer.elapsed_seconds / 60;
    assert_eq!(total_minutes, 30);
    let final_cost = crate::billing_pricing::snap_cost_for_minutes(
        total_minutes as u32,
        2500,    // rate_paise_per_minute
        70000,   // 30-min pkg price (₹700)
        90000,   // 60-min pkg price (₹900)
    );
    assert_eq!(final_cost, 70000, "Cumulative 30 min must snap to 30-min pkg ₹700, not ₹750");
}
