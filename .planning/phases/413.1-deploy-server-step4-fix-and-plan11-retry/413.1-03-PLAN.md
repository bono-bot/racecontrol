# Fix pattern — forfiles mtime guard (defense-in-depth)

Windows `forfiles` has `/D -N` (files modified N or more days ago). For 3 days (72h):
```cmd
forfiles /M racecontrol-prev.exe /D -3 /C "cmd /c del /Q @file" 2>nul
```

This is a self-gating delete: if prev is younger than 72h, `forfiles` finds no match and the inner `del` never runs. If prev is 72h+ old, it deletes.
