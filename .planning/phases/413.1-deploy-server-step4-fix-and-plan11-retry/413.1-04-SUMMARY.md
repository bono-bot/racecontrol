# Phase 413.1 Plan 04: StartRCTemp Retirement Summary

**One-liner:** Retire StartRCTemp in deploy-server.sh Step 5 — live investigation via rc-sentry /exec proved Run-As-User=ADMIN + Logon Mode=Interactive only causes the R1 recovery silent-no-op; Option A selected autonomously per plan conditional checkpoint.

## What was done

### Task 1 — Live investigation

Fetched SENTRY_KEY from server via SSH (`ssh ADMIN@100.125.108.37 'type C:\RacingPoint\racecontrol.toml | findstr sentry'`). Ran all 6 investigation commands specified in the plan `<context>` block against rc-sentry `/exec` on server .23:

| # | Command | Result |
|---|---------|--------|
| 1 | `schtasks /Query /TN StartRCTemp /V /FO LIST` | Captured full field list (Run As User, Logon Mode, Task To Run, Status, etc.) |
| 2 | `schtasks /Query /TN StartRCDirect /V /FO LIST` | Captured full field list for comparison |
| 3 | `schtasks /Query /TN StartRCTemp /XML` | Full XML dump — `<LogonType>InteractiveToken</LogonType>` under S-1-5-21-...-1002 human-user SID |
| 4 | `schtasks /Query /TN StartRCDirect /XML` | Full XML dump — S-1-5-18 (SYSTEM) principal, no LogonType required |
| 5 | `type C:\RacingPoint\start-racecontrol.bat` | Full bat file contents revealed bat does NOT directly start racecontrol.exe |
| 6 | `schtasks /Query /TN StartRCTemp /FO LIST \| findstr Status` | Confirmed Status: Ready (not Disabled — meaning schtask IS callable) |

**Key finding — Dual defect identified:**

1. **Logon Mode / Run As User incompatibility with non-interactive context** — StartRCTemp's `Interactive only` logon mode under the `ADMIN` human-user principal silently no-ops when ADMIN is not interactively logged in. This is the exact failure mode `provision-startrcdirect.ps1:12-18` explicitly documents as the reason StartRCDirect was created with `/RU SYSTEM /LO SERVICE`.

2. **start-racecontrol.bat does not start racecontrol.exe directly** — The bat only performs binary-swap logic + launches `start-racecontrol-watchdog.ps1` via `start "" /B powershell`. Racecontrol is launched indirectly via watchdog.ps1:111 which itself calls `schtasks /Run /TN StartRCDirect`. A 4-hop chain with 2 failure modes.

Committed as `17cb6b8e` (`docs(413.1-04): Task 1 StartRCTemp vs StartRCDirect schtask investigation`).
