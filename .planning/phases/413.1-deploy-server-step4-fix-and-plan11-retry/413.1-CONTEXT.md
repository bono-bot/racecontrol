## Implementation Decisions

### Deploy-server.sh Step 4 swap-line fix

- **Locked:** Use the `CLAUDE.md > Deploy > Server binary swap: rename, don't overwrite` 3-step `ren` sequence. Current Step 4 uses `move /Y` with forward-slash paths — this is a regression against the standing rule.
- **Required sequence:**
  ```
  del C:\RacingPoint\racecontrol-prev.exe
  ren C:\RacingPoint\racecontrol.exe racecontrol-prev.exe
  ren C:\RacingPoint\racecontrol-new.exe racecontrol.exe
  ```
- **Auto-recover on step 3 failure:** `ren racecontrol-prev.exe racecontrol.exe` (no-binary-left guard). Explicitly add this.
- **Preserve backward-slash paths throughout.** Forward slashes work in many Windows contexts but fail via rc-sentry `/exec` cmd.exe invocation ("The system cannot find the path specified").

### !errorlevel! elimination

- **Locked:** Replace all `!errorlevel!` with `%errorlevel%` OR test return codes inline via `&&` / `||` chaining. rc-sentry `/exec` runs commands without `cmd /v:on` so DelayedExpansion `!VAR!` is not available.
- **Evidence:** Prior agent observed raw stdout `SWAP_FAILED_EL=!errorlevel!` (literal string echoed) — confirms DelayedExpansion is off.

### StartRCTemp / StartRCDirect

- **Observation:** During R1 recovery (2026-04-18 08:12 IST), `schtasks /Run /TN StartRCTemp` silently returned success but did NOT start racecontrol.exe. `schtasks /Run /TN StartRCDirect` then succeeded immediately.
- **Open question:** Is StartRCTemp structurally broken (e.g., schtasks points to a deleted path, or its bat wrapper has a bug), OR was this a transient state post-rollback? Planner to decide: fix StartRCTemp, OR migrate deploy-server.sh to StartRCDirect, OR use both with failover.

### racecontrol-prev.exe preservation

- **Locked:** 72h rollback window per CLAUDE.md standing rule. The R1 recovery run observed prev.exe disappearing during recovery. Add explicit guard so cleanup paths (R1 rollback, deploy-server.sh step N, start-racecontrol.bat) do NOT delete prev.exe within 72h. Timestamp check: `dir C:\RacingPoint\racecontrol-prev.exe /TC` — skip delete if mtime < 72h.

### rc-sentry /exec swap unit test

- **Locked:** Add unit test that simulates the rc-sentry `/exec` shell context (no DelayedExpansion, cmd.exe parsing rules) and runs the deploy-server.sh Step 4 swap against a mock filesystem. Catches `move /Y`, `!errorlevel!`, and other classes in CI before live.

<specifics>
## Specific Ideas

### Defect 1: forward-slash paths
Exact line (before Phase 413, then through Plans 05/06/07 untouched):
```
move /Y C:/RacingPoint/racecontrol-new.exe C:/RacingPoint/racecontrol.exe && echo SWAPPED || echo SWAP_FAILED_EL=!errorlevel!
```
Replace with:
```
del /Q C:\RacingPoint\racecontrol-prev.exe 2>nul
ren C:\RacingPoint\racecontrol.exe racecontrol-prev.exe || (echo SWAP_FAILED_EL=%errorlevel% & exit /b 1)
ren C:\RacingPoint\racecontrol-new.exe racecontrol.exe || (ren C:\RacingPoint\racecontrol-prev.exe racecontrol.exe & echo SWAP_FAILED_RECOVERED & exit /b 2)
echo SWAPPED
```
Note: `ren racecontrol.exe racecontrol-prev.exe` works on a RUNNING process — Windows permits rename of locked executable, only delete is blocked.

### Defect 2: !errorlevel! → %errorlevel%
Grep: `grep -n '!errorlevel!' scripts/deploy-server.sh` — fix every occurrence.

### Defect 3: racecontrol-prev.exe preservation
Add guard to any `del racecontrol-prev.exe` or cleanup step:
```
for %%A in (C:\RacingPoint\racecontrol-prev.exe) do if %%~tA LSS [72h-ago] del /Q %%A
```
(Exact syntax per planner discretion — just the principle: don't delete prev within 72h window.)

### Defect 4: StartRCTemp silent-fail
Planner to investigate via rc-sentry `/exec`:
```
schtasks /Query /TN StartRCTemp /V /FO LIST
schtasks /Query /TN StartRCDirect /V /FO LIST
```
Compare the "Task To Run" fields. Likely StartRCTemp points to a stale path or bat file. Decision: fix OR retire.
