# Test harness design

The test harness has THREE layers:

**Layer 1 — Static invariants (grep-enforced).** Fast; runnable in any bash context. Asserts:
- `grep -c '!errorlevel!' scripts/deploy-server.sh` == 0 (R2)
- `grep -c 'move /Y C:/RacingPoint/racecontrol-new' scripts/deploy-server.sh` == 0 (R1 — broken line gone)
- `grep -c 'SWAP_FAILED_RECOVERED' scripts/deploy-server.sh` >= 1 (R1 — auto-recover present)
- `grep -c 'ren C:\\\\RacingPoint\\\\racecontrol.exe racecontrol-prev.exe' scripts/deploy-server.sh` >= 1 (R1 — 3-step ren present)
- `grep -c 'forfiles /M racecontrol-prev.exe /D -3' scripts/deploy/start-racecontrol.bat` >= 1 (R3 — 72h guard present)

**Layer 2 — Dynamic cmd.exe simulation (safety-hardened per revision Issue 4).** Extracts the Step 4 swap payload from deploy-server.sh's curl JSON body, rewrites the production path to a sandbox path via a SINGLE safe sed substitution, verifies the rewrite via a pre-run guard, then feeds the result to `cmd.exe /C` in a sandbox `C:\RacingPoint-test-413-<pid>\` directory with mock binaries, asserts stdout. This layer requires cmd.exe availability — works on Windows native (Git Bash + cmd.exe in PATH), WSL, skipped gracefully on pure Linux CI.

**Layer 3 — forfiles behavioral regression test (addresses revision Issue 8).** Writes a fake staged binary (`racecontrol-aaaaaaaa.exe`) into the sandbox, touches prev.exe with fresh mtime (within last minute), invokes `cmd.exe /C` with CWD set to the sandbox to run a minimal bat snippet that mirrors start-racecontrol.bat lines 8-19 (the staged-binary cleanup path). Asserts prev.exe still exists post-invocation (the 72h guard prevented its deletion). This is the ONLY way to catch a broken forfiles guard — grep (Layer 1) proves presence, not semantics.

# Safe sed path-rewrite (revision Issue 4 fix)

Original broken pattern:
```bash
SWAP_CMD_TEST=$(echo "$SWAP_CMD" | sed "s|C:\\\\RacingPoint\\\\|${TEST_ROOT//\//\\\\}\\\\|g" | sed 's|/c/|C:\\|')
```

Problems: (a) `${TEST_ROOT//\//\\\\}` is a malformed bash pattern substitution that can produce corrupt output depending on shell, (b) the follow-up `sed 's|/c/|C:\\|'` doesn't compose correctly when TEST_ROOT is already a Windows path, (c) no guard asserts the rewrite succeeded — production paths can leak into the test command unnoticed.

New pattern (simple, auditable, safe):
```bash
# TEST_ROOT is a Windows path from the start — no /c/ → C:\ conversion needed.
# cmd.exe speaks Windows paths natively; we build the command entirely in Windows-path form.
TEST_ROOT_WIN="C:\\RacingPoint-test-413-$$"
TEST_ROOT_BASH="/c/RacingPoint-test-413-$$"  # for bash-side file ops only
mkdir -p "$TEST_ROOT_BASH"
trap 'rm -rf "$TEST_ROOT_BASH" 2>/dev/null' EXIT

# Single substitution: replace C:\RacingPoint\ → C:\RacingPoint-test-413-<pid>\
# The JSON payload uses DOUBLED backslashes (C:\\RacingPoint\\) — that's what sed matches against.
SWAP_CMD_TEST=$(echo "$SWAP_CMD" | sed 's|C:\\\\RacingPoint\\\\|C:\\\\RacingPoint-test-413-'"$$"'\\\\|g')

# Pre-run guard — abort if production path still present
if echo "$SWAP_CMD_TEST" | grep -Fq 'C:\\RacingPoint\\'; then
    echo "UNSAFE: test would touch production paths — sed rewrite FAILED"
    echo "  SWAP_CMD_TEST: $SWAP_CMD_TEST"
    exit 2
fi

# Further safety: normalize quadruple-backslash JSON encoding back to the double-backslash cmd.exe form
# Layer 1 already enforces zero occurrences of C:/RacingPoint/racecontrol*.exe, so forward-slash paths
# are impossible in the payload post-Plan-01.
```

# Scenario C hardening (revision Issue 10 fix)

Drop the "best-effort — may fall back to grep invariant" pattern. Use a deterministic setup:

1. Create `racecontrol.exe` in the sandbox (OLD-BINARY content).
2. Create `racecontrol-new.exe` as a regular file (NEW-BINARY content).
3. Create a `racecontrol.exe.lockholder` PowerShell process that opens `racecontrol.exe` with exclusive-read via `[System.IO.File]::Open()` — this makes the 2nd `ren` (racecontrol-new.exe → racecontrol.exe) fail deterministically because Windows can't overwrite a file held with exclusive access. Clean up the PowerShell process via trap on test exit.

**Alternative if PowerShell lock approach is fragile on the test runner:** pre-create a `racecontrol.exe` AFTER the first ren succeeds, using a sandwich pattern:
```bash
# Setup: create a "barrier" that forces the second ren to fail
(sleep 0.5 && echo "BARRIER" > "$TEST_ROOT_BASH/racecontrol.exe") &
BARRIER_PID=$!
OUTPUT=$(cmd.exe /C "$SWAP_CMD_TEST" 2>&1 || true)
wait $BARRIER_PID
```

The barrier creates a new racecontrol.exe between the 1st ren (which renames it to prev) and the 2nd ren (which tries to rename new→racecontrol.exe — fails because racecontrol.exe already exists as a fresh file). This triggers `SWAP_FAILED_RECOVERED`.

**If BOTH deterministic setups prove unreliable on the CI runner:** Scenario C is EXPLICITLY DROPPED (not "fallback to grep"). Document this in the test script as a comment, and the plan accepts that live Task 3 Plan 06 canary provides the full-flow coverage. No weak-coverage gap is introduced — Layer 1's invariant (`SWAP_FAILED_RECOVERED >=1 in script`) proves the code path exists; the canary exercises it in production.

# Layer 3 forfiles regression (revision Issue 8 fix)

Plan 03 adds `forfiles /M racecontrol-prev.exe /D -3` to `start-racecontrol.bat`. Layer 1 grep proves presence; Layer 3 proves behavior.

Test sequence:
```bash
# Layer 3 — forfiles 72h guard behavioral regression
if command -v cmd.exe >/dev/null 2>&1; then
    echo "--- Layer 3: forfiles 72h guard behavioral regression ---"

    FORFILES_TEST_ROOT="/c/RacingPoint-test-413-forfiles-$$"
    mkdir -p "$FORFILES_TEST_ROOT"
    trap 'rm -rf "$FORFILES_TEST_ROOT" 2>/dev/null' EXIT

    # Setup: fresh prev.exe (mtime = now) + a fake staged hash-named binary to trigger the bat's conditional branch
    echo "PREV-BINARY" > "$FORFILES_TEST_ROOT/racecontrol-prev.exe"
    echo "CURRENT-BINARY" > "$FORFILES_TEST_ROOT/racecontrol.exe"
    echo "STAGED-BINARY" > "$FORFILES_TEST_ROOT/racecontrol-aaaaaaaa.exe"

    # Invoke a minimal bat snippet that mirrors start-racecontrol.bat lines 8-19
    # (we don't invoke the real bat because it would launch racecontrol.exe; instead we
    # extract the cleanup/swap block and run it standalone in the sandbox).
    cmd.exe /C "cd /d $(cygpath -w "$FORFILES_TEST_ROOT") & set STAGED=racecontrol-aaaaaaaa.exe & forfiles /M racecontrol-prev.exe /D -3 /C \"cmd /c del /Q @file\" 1>nul 2>nul & if exist racecontrol.exe if not exist racecontrol-prev.exe ren racecontrol.exe racecontrol-prev.exe 1>nul 2>nul"

    # Assert prev.exe still exists + still contains PREV-BINARY (guard prevented deletion)
    if [ ! -f "$FORFILES_TEST_ROOT/racecontrol-prev.exe" ]; then
        fail "Layer 3: forfiles 72h guard FAILED — prev.exe was deleted despite mtime < 72h"
    fi
    if [ "$(cat "$FORFILES_TEST_ROOT/racecontrol-prev.exe")" != "PREV-BINARY" ]; then
        fail "Layer 3: forfiles guard passed but prev.exe content changed — rename-clobber happened"
    fi
    pass "Layer 3: forfiles 72h guard prevented premature delete; prev.exe intact with original content"
fi
```
