    1. Create `crates/rc-agent/src/lock_screen/window.rs`:
       - `pub fn spawn_lock_window(state: Arc&lt;Mutex&lt;LockScreenState&gt;&gt;, hwnd_slot: Arc&lt;Mutex&lt;Option&lt;isize&gt;&gt;&gt;)` — spawns a dedicated `std::thread` (NOT tokio) that:
         a. Calls `font::install_embedded_fonts()` (font install must happen on same thread that creates window, or at minimum before CreateFont calls)
         b. Registers window class "RacingPointLockScreen" with `RegisterClassExW`. Use `CS_HREDRAW | CS_VREDRAW`. Set `hCursor: std::ptr::null_mut()` (cursor managed per-state).
         c. Creates `LockWindowState` struct on heap (Box::new) containing: `state: Arc<Mutex<LockScreenState>>`, `res: LockGdiResources` (created here on window thread)
         d. Calls `get_virtual_screen_bounds()` (already exists in lock_screen.rs line 34 — move to or re-export from mod.rs) for (vx, vy, vw, vh)
         e. `CreateWindowExW(WS_EX_TOPMOST, ...)` with `WS_POPUP | WS_VISIBLE`, position (vx, vy, vw, vh). Pass `LockWindowState` pointer as LPVOID param.
         f. Store HWND in hwnd_slot. Log window dimensions.
         g. `SetTimer(hwnd, 1, 1000, None)` — 1-second repaint timer (sufficient for countdown)
         h. `GetMessageW` loop with `TranslateMessage` + `DispatchMessageW`
         i. On loop exit: `font::uninstall_embedded_fonts()`, log cleanup
       - `unsafe extern "system" fn lock_wnd_proc(hwnd, msg, wparam, lparam) -> LRESULT`:
         - `WM_CREATE`: Extract `LockWindowState*` from `CREATESTRUCT.lpCreateParams`, store in `SetWindowLongPtrW(hwnd, GWLP_USERDATA, ptr)`
         - `WM_TIMER`: Call `InvalidateRect(hwnd, null, FALSE)` to trigger repaint
         - `WM_PAINT`: Retrieve `LockWindowState*` from GWLP_USERDATA, call `painter::paint_lock_screen(hwnd, &state, &res, vw, vh)` (see Task 2 painter below)
         - `WM_APP + 1` (hide): `ShowWindow(hwnd, SW_HIDE)`
         - `WM_APP + 2` (repaint): `InvalidateRect(hwnd, null, FALSE)`
         - `WM_APP + 3` (show): `ShowWindow(hwnd, SW_SHOW)` + `SetForegroundWindow(hwnd)`
         - `WM_DESTROY`: `PostQuitMessage(0)`
         - `WM_SETCURSOR`: If state is ScreenBlanked, `SetCursor(null)` + return TRUE to hide cursor. Otherwise `SetCursor(LoadCursorW(null, IDC_ARROW))`.
         - Default: `DefWindowProcW`
