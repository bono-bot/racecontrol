  <action>
Create `tests/page-crawler/crawl.spec.ts` -- the main crawler Playwright test file.

**CLI filtering via environment variables** (since Playwright tests use env vars for parameterization):
- `CRAWL_APP`: filter by app name -- 'web', 'admin', 'kiosk', or unset for all
- `CRAWL_PAGE`: filter by page path -- e.g. '/billing' or '/kiosk/staff', or unset for all pages
- `CRAWL_PAGES`: comma-separated list of paths -- e.g. '/billing,/fleet,/drivers'

**Implementation:**

```
import { test, expect } from '@playwright/test';
import { getAllRoutes, AppRoute } from './routes';
import { ensureAuth } from './auth-setup';
import * as fs from 'fs';
import * as path from 'path';
```

Use `test.describe` for each app. Inside each describe:

1. Read `CRAWL_APP` env var. If set and doesn't match current app, `test.skip()` the entire describe block.

2. `test.beforeAll`: Call `ensureAuth(baseUrl)` to get the storageState path. Store it.

3. For each route in the app's manifest, create a test case via a loop:
   - Check `CRAWL_PAGE` / `CRAWL_PAGES` env vars -- if set and route doesn't match, `test.skip()`
   - Create a new browser context with `storageState` (if route requires auth)
   - Navigate to `baseUrl + route.path`
   - Wait for `networkidle` state (with 15s timeout)
   - If route has `waitForSelector`, wait for that selector (5s timeout, catch and log if missing)
   - Generate screenshot path: `tests/screenshots/{app}/{sanitized-route}/{timestamp}.png`
     - `app` = 'web', 'admin', or 'kiosk'
     - `sanitized-route` = route.path with `/` replaced by `_`, leading `_` removed (e.g. `/billing/history` -> `billing_history`)
     - `timestamp` = ISO format `YYYY-MM-DDTHH-MM-SS` (colons replaced with dashes for Windows compat)
   - Create the directory recursively if it doesn't exist
   - Call `page.screenshot({ fullPage: true, path: screenshotPath })`
   - Assert the screenshot file exists and has size > 0
   - Close the context

4. After all tests complete, log a summary to stdout: total pages crawled, total screenshots saved, any failed pages.

**Important implementation details:**
- Use `test.setTimeout(60_000)` per test (some pages may be slow)
- Catch navigation errors gracefully -- if a page returns 404 or 500, still capture the screenshot (the error page IS useful evidence) but log a warning
- For kiosk routes, the basePath is `/kiosk` so routes already include it (e.g. `/kiosk/staff`)
- The `/pod/[number]` route uses `/pod/1` as representative
- Do NOT use `test.describe.parallel` -- serial execution prevents resource contention
