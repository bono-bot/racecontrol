# Plan 344-02: Node version pin

## Objective

Pin Node version to 22 LTS via three layers so the better-sqlite3 ABI mismatch can't silently return.

## Tasks

### Task 1: Add `.nvmrc`

Create `racingpoint-admin/.nvmrc` containing `22`. Developers using `nvm` will auto-switch on `cd`.

### Task 2: Add `engines` to package.json

Set `"engines": {"node": ">=22.0.0 <23.0.0"}`. npm will warn on `npm install` if the version is wrong.

### Task 3: Add npm scripts for deploy/verify

Add convenience scripts:
```json
"deploy": "bash scripts/admin-deploy.sh",
"deploy:rollback": "bash scripts/admin-deploy.sh --rollback",
"deploy:dry-run": "bash scripts/admin-deploy.sh --dry-run",
"verify": "node scripts/verify-deploy.js",
"verify:static": "node scripts/verify-deploy.js --skip-live"
```

### Task 4: Hard Node check in `admin-deploy.sh` (already done in Plan 01)

The `admin-deploy.sh` already contains:
```bash
NODE_VER="$(node -v)"
case "$NODE_VER" in
  v22.*) ;;
  *) echo "[admin-deploy] FATAL: need Node 22.x, got $NODE_VER"; exit 1 ;;
esac
```

## Done criteria

- `.nvmrc` contains `22`
- `package.json#engines.node` is `>=22.0.0 <23.0.0`
- `package.json#scripts` has deploy/verify/rollback commands
- `admin-deploy.sh` hard-fails on wrong Node major
