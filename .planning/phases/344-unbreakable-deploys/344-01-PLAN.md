# Plan 344-01: admin-deploy.sh + verify-deploy.js + server-bootstrap.js

## Objective

Build the three core deploy scripts:
1. `admin-deploy.sh` — unified bash deploy for venue + cloud
2. `verify-deploy.js` — post-deploy verification gate
3. `server-bootstrap.js` — env loader wrapper for `.next/standalone/server.js`

Plus update `next.config.ts` with `outputFileTracingRoot` to prevent the build-machine-path bug from CLAUDE.md.

## Tasks

### Task 1: Create `server-bootstrap.js`

**File:** `racingpoint-admin/scripts/server-bootstrap.js`

Thin wrapper that:
1. Loads env vars from `.env.production.local` (if present) using Node's built-in parsing (no `dotenv` dep)
2. Asserts required env vars present, exits 1 with clear error if any missing
3. Requires `./server.js` (the Next.js standalone entrypoint)

Run from inside `.next/standalone/`. This is the canonical entrypoint on both venue + cloud.

### Task 2: Create `verify-deploy.js`

**File:** `racingpoint-admin/scripts/verify-deploy.js`

Runs 5 checks, exits 1 on ANY failure:

1. **Static assets** — `fs.existsSync('.next/standalone/.next/static/')` and has at least 1 file
2. **better-sqlite3 loads** — `require('better-sqlite3')(':memory:')` doesn't throw
3. **Env vars present** — `RC_URL`, `RC_JWT_SECRET`, `NEXT_PUBLIC_API_URL`, `NEXT_PUBLIC_GATEWAY_URL`
4. **HTTP listener** — `fetch('http://localhost:3201/api/health')` returns 200
5. **Login round-trip** — `POST /api/auth/login` with `ADMIN_TEST_PIN` (env var) returns 200 with Set-Cookie header

Takes an optional `--skip-live` flag that skips checks 4 + 5 (for pre-start verification before the server is running).

### Task 3: Create `admin-deploy.sh`

**File:** `racingpoint-admin/scripts/admin-deploy.sh`

Unified bash deploy script with these steps, fails loudly on any error:

```bash
#!/usr/bin/env bash
set -euo pipefail

# 0. Sanity — Node version + cwd
node -v | grep -q '^v22\.' || { echo "FATAL: Need Node 22, got $(node -v)"; exit 1; }
[ -f package.json ] || { echo "FATAL: Run from racingpoint-admin/ root"; exit 1; }

# 1. Archive previous build
if [ -d ".next/standalone" ]; then
  rm -rf .next/prev-standalone
  mv .next/standalone .next/prev-standalone
fi

# 2. Clean install + build
npm ci
npx next build

# 3. Copy static assets into standalone tree (Next known gap)
cp -r .next/static .next/standalone/.next/static
cp -r public .next/standalone/public

# 4. Rebuild native bindings against runtime Node
cd .next/standalone && npm rebuild better-sqlite3 && cd -

# 5. Copy bootstrap + env file
cp scripts/server-bootstrap.js .next/standalone/server-bootstrap.js
[ -f .env.production.local ] && cp .env.production.local .next/standalone/.env.production.local

# 6. Pre-start verify (skip live checks)
node scripts/verify-deploy.js --skip-live

# 7. Restart service (caller-provided command via $ADMIN_RESTART_CMD)
if [ -n "${ADMIN_RESTART_CMD:-}" ]; then
  eval "$ADMIN_RESTART_CMD"
else
  echo "WARN: No ADMIN_RESTART_CMD set — manual restart required"
fi

# 8. Wait for listener up (30s budget)
for i in $(seq 1 30); do
  if curl -sf http://localhost:3201/api/health >/dev/null 2>&1; then
    break
  fi
  sleep 1
done

# 9. Full verify (live checks)
node scripts/verify-deploy.js

echo "DEPLOY OK"
```

### Task 4: Add `--rollback` flag

Extend `admin-deploy.sh` to support `./admin-deploy.sh --rollback`:

```bash
if [ "${1:-}" = "--rollback" ]; then
  [ -d .next/prev-standalone ] || { echo "FATAL: no prev-standalone to roll back to"; exit 1; }
  rm -rf .next/standalone
  mv .next/prev-standalone .next/standalone
  [ -n "${ADMIN_RESTART_CMD:-}" ] && eval "$ADMIN_RESTART_CMD"
  node scripts/verify-deploy.js
  echo "ROLLBACK OK"
  exit 0
fi
```
