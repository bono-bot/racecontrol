Write a bash script at `.planning/phases/396-architecture-conventions-docs/verify-396.sh`. It MUST:

1. Start with `#!/usr/bin/env bash` and `set -u` (not `set -e` — we want to collect ALL failures, not bail on first).
2. Define variables at top:
   - `PHASE_DIR="$(cd "$(dirname "$0")" && pwd)"`
   - `CONV="$PHASE_DIR/CONVENTIONS.md"`
   - `ARCH="$PHASE_DIR/ARCHITECTURE.md"`
   - `PASS=0 FAIL=0 PENDING=0`
3. Define helper functions:
   - `pass() { echo "  PASS: $1"; PASS=$((PASS+1)); }`
   - `fail() { echo "  FAIL: $1"; FAIL=$((FAIL+1)); }`
   - `pending() { echo "  PENDING: $1"; PENDING=$((PENDING+1)); }`
4. Implement these 13 checks in order, each as a labeled section with `echo "[N/13] <label>"`:

   **Check 1 — Both files exist (gating):**
   `test -f "$CONV"` and `test -f "$ARCH"`. If either missing, call `pending` for EVERY subsequent check that targets the missing file. Use flags `CONV_OK` / `ARCH_OK` to drive later checks into pending mode instead of failing.

   **Check 2 — Line cap:** `[ "$(wc -l < "$CONV")" -le 500 ]` and same for ARCH (only if *_OK).

   **Check 3 — Guiding principle verbatim in both:** `grep -qF "If a rule is not enforced mechanically" "$CONV"` and same for ARCH.

   **Check 4 — Deferred Rules section present in CONVENTIONS:** `grep -q '^## Deferred Rules' "$CONV"`.

   **Check 5 — All 8 rules demoted to Deferred:** `awk '/^## Deferred Rules/,/^## [^#]/' "$CONV" | grep -cE '^\| [1-8] ' ` equals 8.

   **Check 6 — Every Deferred row cites phase 397–412:** `awk '/^## Deferred Rules/,/^## [^#]/' "$CONV" | grep -cE '(Phase|phase) (39[7-9]|4[0-1][0-9])'` is >= 8.

   **Check 7 — ARCHITECTURE has >= 11 artifact-type rows:** `grep -c '^| \[DEFERRED' "$ARCH"` >= 11.

   **Check 8 — Every ARCHITECTURE decision table row either cites a file path OR is [DEFERRED — Phase N]:** run `awk '/^\| /' "$ARCH" | grep -vE '(\[DEFERRED|Enforcer|Destination|---|Artifact type)'` and assert line count is 0 (no orphan rows). Use `wc -l` and numeric compare.

   **Check 9 — No stray live Enforcer citations:** `! grep -qE '^Enforcer:' "$CONV"` and same for ARCH (research says zero live citations expected).

   **Check 10 — D-12 footer present:** `grep -qF 'Canonical home: workspace/' "$CONV"` and same for ARCH.

   **Check 11 — Rule #9 (canonical-source marker) NOT added per D-05:** `! grep -q 'canonical-source' "$CONV"` (or only in a "not added" note — use `grep -q 'canonical-source' "$CONV" && grep -q 'not added' "$CONV" || ! grep -q 'canonical-source' "$CONV"`).

   **Check 12 — 393 back-references:** `[ "$(grep -c '(Phase 393' "$ARCH")" -ge 3 ]` and `[ "$(grep -c '(Phase 393' "$CONV")" -ge 2 ]`.

   **Check 13 — ARCHITECTURE has `## Adding a New Artifact Type` section:** `grep -q '^## Adding a New Artifact Type' "$ARCH"`.

5. At end, print summary:
   ```
   echo ""
   echo "======================================"
   echo "Phase 396 Verification: $PASS passed / $FAIL failed / $PENDING pending"
   echo "======================================"
   ```
6. Exit code logic:
   - If `$FAIL -gt 0`: `exit 2`
   - Elif `$PENDING -gt 0`: `exit 1` (Wave 0 acceptable — docs not yet written)
   - Else: `exit 0` (all green — ready for Wave 2 sign-off)

7. Make executable: after Write, run `chmod +x .planning/phases/396-architecture-conventions-docs/verify-396.sh` via Bash.

The script must be IDEMPOTENT (re-run-safe — no state files, no side effects except stdout) and MUST NOT crash when files are absent (use the CONV_OK/ARCH_OK gating pattern above).
