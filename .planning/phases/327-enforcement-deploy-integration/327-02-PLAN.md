**Structure (3 sections):**

**Section 1: Build Hash Verification Table (per DEPLOY-02)**
- Accept optional `--expected-hash HASH` argument (defaults to `git rev-parse --short HEAD`)
- Define target list with color-coded table output:
  ```
  ╔══════════════════════════════════════════════════════════╗
  ║  BUILD HASH VERIFICATION TABLE                          ║
  ╠════════════╦═══════════╦══════════╦═════════════════════╣
  ║ Target     ║ Expected  ║ Running  ║ Status              ║
  ╠════════════╬═══════════╬══════════╬═════════════════════╣
  ║ Server     ║ abc1234   ║ abc1234  ║ MATCH               ║
  ║ Web :3200  ║ -         ║ HTTP 200 ║ OK                  ║
  ║ Admin :3201║ -         ║ HTTP 200 ║ OK                  ║
  ║ Kiosk :3300║ -         ║ HTTP 200 ║ OK                  ║
  ║ Cloud      ║ abc1234   ║ xyz5678  ║ MISMATCH            ║
  ╚════════════╩═══════════╩══════════╩═════════════════════╝
  ```
- Targets:
  - Server (.23:8080): `curl -s http://192.168.31.23:8080/api/v1/health` -> extract `build_id`
  - Web (.23:3200): `curl -s -o /dev/null -w "%{http_code}" http://192.168.31.23:3200` -> check 200
  - Admin (.23:3201): `curl -s -o /dev/null -w "%{http_code}" http://192.168.31.23:3201` -> check 200
  - Kiosk (.23:3300): `curl -s -o /dev/null -w "%{http_code}" http://192.168.31.23:3300/kiosk` -> check 200
  - Cloud (Bono VPS): `curl -s --max-time 10 http://srv1422716.hstgr.cloud:8080/api/v1/health` -> extract `build_id`
- Color: green for MATCH/OK, red for MISMATCH/DOWN, yellow for TIMEOUT
- If cloud is unreachable, show TIMEOUT (not failure -- cloud may be intentionally down)
- This section is informational -- it does NOT cause exit failure (mismatches are warnings)

**Section 2: Page Crawler Auto-Run (per DEPLOY-01)**
- Run the page crawler: `npx playwright test --config tests/page-crawler/playwright.config.ts`
- Capture exit code
- If crawler fails (non-zero exit), print which pages failed and continue to section 3

**Section 3: Visual Regression Check (per DEPLOY-03)**
- Run visual regression comparison: `npx playwright test --config tests/visual-regression/playwright.config.ts`
- If regressions detected (exit code non-zero):
  - Print diff summary
  - Print: "VISUAL REGRESSION DETECTED -- review diffs in tests/visual-regression/test-results/"
  - Exit with code 1 (deploy failure)
- If baselines don't exist yet (first run), treat as success with a note

**Script conventions (match deploy-server.sh style):**
- Shebang: `#!/usr/bin/env bash`
- `set -euo pipefail` at top
- Color variables: RED, GREEN, YELLOW, CYAN, NC (No Color)
- Helper functions: `info()`, `pass()`, `fail()`, `warn()`
- SCRIPT_DIR detection: `SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"`
- REPO_DIR: `$(cd "${SCRIPT_DIR}/.." && pwd)`
- Accept `--skip-crawler` flag to only run hash verification (for quick checks)
- Accept `--skip-vr` flag to skip visual regression (useful when baselines haven't been created yet)
- Total runtime target: < 120 seconds for full run
