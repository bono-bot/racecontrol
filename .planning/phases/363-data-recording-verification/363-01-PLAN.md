   ```rust
   pub fn expected_laps(session_type: &str, minutes: u32) -> u32
   ```
   Implements D-01 floor heuristic per CONTEXT.md decision:
   - Match session_type lowercased: `"hotlap"` → `(minutes / 2).max(1)`
   - All other types (trackday, practice, race, default) → `(minutes / 3).max(1)`

3. **Pure function**
   ```rust
   pub fn compute_lap_flag(expected: u32, actual: u32) -> LapCountFlag
   ```
   - If expected == 0 → `Unverified`
   - If `(actual as f64) < (expected as f64) * 0.9` → `UnderRecorded` (per D-02, directional)
   - Else → `Ok`

4. **Pure function**
   ```rust
   pub fn coverage_pct(seconds_covered: u32, total_seconds: u32) -> f64
   ```
   - If total_seconds == 0 → 0.0
   - Else → `(seconds_covered as f64 / total_seconds as f64) * 100.0`

5. **Pure function**
   ```rust
   pub fn compute_suspect(lap_flag: LapCountFlag, coverage: Option<f64>) -> (bool, Vec<&'static str>)
   ```
   - reasons: push "under_recorded" if lap_flag == UnderRecorded; push "telemetry_low" if coverage.map(|c| c < 80.0).unwrap_or(false); push "unverified" if coverage.is_none() OR lap_flag == Unverified
   - suspect = !reasons.is_empty() (per D-06: `lap_count_flag != OK OR telemetry_coverage_pct < 80`)
