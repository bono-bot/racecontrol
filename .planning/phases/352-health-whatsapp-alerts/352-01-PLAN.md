**7 probe functions** (per D1):

- `probe_db_writable(db: &SqlitePool) -> SubsystemStatus` — INSERT/DELETE on `server_health_probe` table (adapt from server_diagnostics.rs `check_db_health()`). Return latency_ms, error_code `DB_WRITE_FAILED` on failure.
- `probe_rc_backend() -> SubsystemStatus` — Always ok (self-check: if we're responding, we're up). latency_ms: 0.

- `probe_whatsapp_api(config: &Config) -> SubsystemStatus` — Call existing `check_evolution_health()` pattern: HEAD request to Evolution API URL with 2s timeout. error_code `WHATSAPP_UNREACHABLE`.
- `probe_fleet_connectivity(state: &AppState) -> SubsystemStatus` — Count pods with `ws_connected: true` from fleet health state. Detail: "N/8 pods connected". Degrade if < expected count.
- `probe_admin_db(state: &AppState) -> SubsystemStatus` — If AppState has an admin_db pool, test read. If not, check file existence of admin.db at configured path. error_code `ADMIN_DB_UNAVAILABLE`.

**Background task** `async fn subsystem_health_task(state: Arc<AppState>)`:
- Loop with `tokio::time::interval(Duration::from_secs(10))`
- Run all 7 probes (concurrently with `tokio::join!` where independent)
- Build `HashMap<String, SubsystemStatus>` with keys: `"db_writable"`, `"rc_backend"`, `"disk_free"`, `"cloud_sync"`, `"whatsapp_api"`, `"fleet_connectivity"`, `"admin_db"`
- Compare with previous state: if a subsystem transitions ok->not_ok, check dedup map, fire alert if not suppressed
- If subsystem transitions not_ok->ok, fire recovery alert
- Update `SUBSYSTEM_STATE` via write lock (clone results, drop lock before any async work — standing rule)
- Evict dedup entries older than 10 minutes on each cycle

async fn dispatch_subsystem_alert(config: &Config, db: &SqlitePool, subsystem: &str, error_code: &str, detail: &str) {
    let msg = format!(
        "[RP ALERT] Subsystem Degraded: {}\nError: {}{}\nServer: {} | {}",
        subsystem, error_code,
        if detail.is_empty() { String::new() } else { format!(" — {}", detail) },
        if config.is_cloud { "cloud" } else { "venue (.23)" },
        crate::whatsapp_alerter::ist_now_string()
    );
    // Primary: direct Evolution API
    crate::whatsapp_alerter::send_whatsapp(config, &msg).await;
    
    // Record in alert_incidents per D4/OPS-05
    record_subsystem_incident(db, subsystem, error_code, &msg).await;
}

async fn dispatch_recovery_alert(config: &Config, db: &SqlitePool, subsystem: &str, duration_secs: u64) {
    let msg = format!(
        "[RP RESOLVED] {} recovered (was down {}m {}s) | {}",
        subsystem, duration_secs / 60, duration_secs % 60,
        crate::whatsapp_alerter::ist_now_string()
    );
    crate::whatsapp_alerter::send_whatsapp(config, &msg).await;
    resolve_subsystem_incident(db, subsystem).await;
}
```

**Incident recording** (per D4/OPS-05):

async fn record_subsystem_incident(db: &SqlitePool, subsystem: &str, error_code: &str, message: &str) {
    let id = uuid::Uuid::new_v4().to_string();
    let corr_id = uuid::Uuid::new_v4().to_string();
    let _ = sqlx::query(
        "INSERT INTO alert_incidents (id, alert_type, subsystem, severity, description, correlation_id)
         VALUES (?, 'subsystem_degraded', ?, 'critical', ?, ?)"
    )
    .bind(&id).bind(subsystem).bind(message).bind(&corr_id)
    .execute(db).await;
}

async fn resolve_subsystem_incident(db: &SqlitePool, subsystem: &str) {
    let _ = sqlx::query(
        "UPDATE alert_incidents SET resolved_at = datetime('now')
         WHERE subsystem = ? AND resolved_at IS NULL AND alert_type = 'subsystem_degraded'"
    )
    .bind(subsystem)
    .execute(db).await;
}
```

**Dedup check** (per D3/OPS-04):
```rust
fn should_alert(subsystem: &str, error_code: &str) -> bool {
    let key = (subsystem.to_string(), error_code.to_string());
    let mut map = DEDUP_MAP.lock().unwrap_or_else(|e| e.into_inner());
    // Evict old entries
    map.retain(|_, v| v.elapsed() < Duration::from_secs(DEDUP_WINDOW_SECS));
    if let Some(last) = map.get(&key) {
        if last.elapsed() < Duration::from_secs(DEDUP_WINDOW_SECS) {
            return false; // suppressed
        }
    }
    map.insert(key, Instant::now());
    true
}
```
