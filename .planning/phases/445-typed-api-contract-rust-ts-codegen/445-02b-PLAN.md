    )]

    **Critical feature-gating rule:** EVERY `#[utoipa::path(...)]` block is wrapped in `#[cfg(feature = "gen-types")]` so the annotations only exist in `gen-types`-enabled builds.     - `-> (StatusCode, Json<ErrorResponse>)` → `body = ErrorResponse` for the success row + list 4xx/5xx rows

    **For request body (POST/PUT/PATCH):** add `request_body = <RequestType>` line if the handler takes a `Json<X>` extractor.
