## 4. V2-alignment delta

V2 MAX_DISCOUNT_PCT ceiling primitive:

**A. Constant + config**
```rust
// crates/racecontrol/src/pricing/discount_ceiling.rs (NEW)
/// V2 maximum discount percent — clamps resolved discount at this cap
/// Captain Q-2-1 disposition: <PENDING-Captain-ratify; RCA proposes 0.50 = 50%>
/// Override via env DISCOUNT_CEILING_PCT_OVERRIDE (logged + alerted on change)
pub const MAX_DISCOUNT_PCT_DEFAULT: f64 = 0.50;

pub fn max_discount_pct(state: &AppState) -> f64 {
    state.config.discount_ceiling_pct.unwrap_or(MAX_DISCOUNT_PCT_DEFAULT)
}

pub fn clamp_discount_pct(requested: f64, state: &AppState) -> ClampResult {
    let cap = max_discount_pct(state);
    if requested <= cap {
        ClampResult::Allowed { pct: requested }
    } else {
        ClampResult::Clamped { original_pct: requested, clamped_pct: cap, cap_source: "MAX_DISCOUNT_PCT" }
    }
}
```
