# §S-146 V1↔V2 RCA — Row 7.6 cookie auth substrate composite (5 sub-gaps)

## 1. Boundary map

**§S-219.11 finding verbatim:** row 7.6 = "no Set-Cookie · no cookie middleware · no logout endpoint · no Domain attribute · no CSRF/rate-limit binding". Grep verification 2026-05-13 IST:

**G-7.6-1: No `Set-Cookie` server-side emission**
- `crates/racecontrol/src/auth_staff.rs:270-284` — staff PIN-login handler returns `Json<LoginResponse> { token, ... }`; no `Response::builder().header("Set-Cookie", ...)` emission
- grep `Set-Cookie\|HttpOnly\|SameSite\|cookie::Cookie` across all crates: **0 hits** (no cookie-axum middleware, no tower-cookies dependency, no manual header emission)
- Client `kiosk/src/components/StaffLoginScreen.tsx:48` sets `document.cookie = kiosk_staff_jwt=${res.token}; path=/; max-age=1800; SameSite=Strict` — client-side only, NOT HttpOnly, NOT secure, XSS-readable

**G-7.6-2: No cookie-extractor middleware**
- `crates/racecontrol/src/auth/middleware.rs:140-164` — JWT auth middleware extracts from `Authorization: Bearer <token>` header ONLY
- No alternative cookie-extractor middleware path; cookie value present in request is ignored
- Failure mode: server emits no cookie + can't read cookie even if present — bidirectional dead zone

**G-7.6-3: No `/staff/logout` endpoint**
- grep `staff_logout\|/staff/logout\|fn logout` returns 0 hits in `crates/racecontrol/src/`
- Session-invalidation has no server-side path; client must clear `document.cookie` locally
- Failure mode: stolen JWT remains valid for 30min (per kiosk max-age=1800) regardless of staff awareness

**G-7.6-4: No `Domain` attribute on cookie**
- `StaffLoginScreen.tsx:48` cookie has `path=/` but no `Domain` directive
- Multi-origin V2 (racingpoint.cloud admin + venue kiosk + POS) cannot share cookie scope
- Failure mode: staff login at kiosk doesn't carry to admin dashboard; staff logs in twice

**G-7.6-5: No CSRF/rate-limit binding**
- No CSRF token coupled to cookie; cookie-only auth (when implemented) would be vulnerable to CSRF
- No per-IP/per-staff rate-limit on `/staff/login` endpoint; unlimited PIN-brute-force attempts
- Composes-with row 7.7 cirs-lookup CSRF gap (sibling)

**Contract test scaffolded:** `racecontrol/tests/contract/staff-session-cookie.spec.ts` (§S-219 iter4 commit b08b0073, 638 lines) — 5 tests covering all 5 sub-gaps with env-gated SKIP-with-reason `V1_NO_SET_COOKIE` + 4 siblings.

```rust
pub async fn staff_login(State<AppState>, Json<LoginRequest>) -> Result<impl IntoResponse> {
    let token = ...; // existing JWT mint
    let cookie = format!(
        "rp_staff_session={}; Path=/; HttpOnly; Secure; SameSite=Lax; Domain=.racingpoint.cloud; Max-Age=1800",
        token
    );

        StatusCode::OK,
        [("Set-Cookie", cookie.as_str())],

    ))
}
```

**B. Cookie-extractor middleware**
```rust
// crates/racecontrol/src/auth/middleware.rs (MODIFY)
async fn extract_staff_jwt(headers: &HeaderMap) -> Option<String> {
    // 1st: Bearer header (Existing — service-key + rc-agent path)
    if let Some(bearer) = extract_bearer(headers) { return Some(bearer); }
    // 2nd: Cookie (NEW — staff browser path)
    if let Some(cookie_hdr) = headers.get("Cookie") {
        if let Ok(s) = cookie_hdr.to_str() {
            for part in s.split(';') {
                let kv = part.trim();
                if let Some(val) = kv.strip_prefix("rp_staff_session=") { return Some(val.to_string()); }
            }
        }
    }
    None
}
```
