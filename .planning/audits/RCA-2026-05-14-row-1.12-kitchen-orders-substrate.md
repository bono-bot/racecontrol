## §4 — V2-alignment delta

The V2-aligned cafe-order surface under Wallet Framing C ("sim+PS5 only on pod-billing; cafe separate") + DoD canonical day 14:42 + R1-C lock + single-kitchen-tablet doctrine:

**A. kitchen_orders table (Phase 1 — THIS RCA):**
```sql
CREATE TABLE kitchen_orders (
    id TEXT PRIMARY KEY,
    session_id TEXT NOT NULL REFERENCES sessions(id),
    source TEXT NOT NULL CHECK (source IN ('cafe/PWA', 'cafe/Kiosk')),
    items_json TEXT NOT NULL,
    total_paise INTEGER NOT NULL CHECK (total_paise >= 0),
    idempotency_key TEXT NOT NULL,           -- UNIQUE via separate index
    placed_at_utc TEXT NOT NULL,
    fulfilled_at_utc TEXT,
    state TEXT NOT NULL DEFAULT 'pending'
        CHECK (state IN ('pending', 'preparing', 'ready', 'cancelled'))
);
```
+ 3 indices: `idx_kitchen_orders_idempotency` (UNIQUE), `idx_kitchen_orders_active_queue` (partial state in {pending,preparing}), `idx_kitchen_orders_session_id` (FK lookup for auto-bill compose).

**B. POST /api/v1/cafe/order endpoint (Phase 2 — DEFERRED):**
Per spec test L49-54 contract: accepts `{customer_id, items: [{sku, qty}], source: "pwa-self" | "kiosk-staff"}` and returns `{order_id, kitchen_routing_id}`. Source-string mapping `pwa-self → cafe/PWA` and `kiosk-staff → cafe/Kiosk` at handler boundary. Idempotency-replay returns prior order_id on UNIQUE constraint violation. Handler computes total_paise from items × cafe_items unit-price. INSERT into kitchen_orders.

**C. GET /api/v1/cafe/kitchen-queue endpoint (Phase 2 — DEFERRED):**
Chef tablet pull endpoint. Returns active queue (state IN {pending, preparing}) ordered by placed_at_utc ASC. Includes items_json + source for chef-side rendering. Auth: staff JWT (kitchen tablet identifies as kiosk-class staff surface). Future WS subscription for push-style updates.

**D. Auto-bill composition to Layer 1.13 (Phase 2-or-3 — DEFERRED):**
At session-close (or auto-bill tick), Layer 1.13 finalize handler SELECTs `SUM(total_paise) FROM kitchen_orders WHERE session_id = ?` and adds to session billing total. Composition surface = session_id FK link. Index idx_kitchen_orders_session_id supports the JOIN cheaply.
